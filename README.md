# quest3-claude-ops

Ponto de coordenação entre duas sessões de Claude Code: a que roda no PC do
Julio (projeto PC) e a que roda em Termux dentro de um Meta Quest 3. Como
não há canal de mensagem direto entre as duas, as instruções e o status
trafegam por aqui — clonar, ler `TASK.md`, executar, atualizar `STATUS.md`,
commit e push.

Não é produto — é ferramental interno de infraestrutura para a exploração de
um agente rodando em AR glasses.
